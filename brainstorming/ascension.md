# Ascension — the Infinite

Reaching 52! once (lifetime) unlocks Ascension. Each Ascension changes the *deck*, so 52! is not the
end but the first landing.

1. **The Joker** (53 cards → 53! ≈ 4.3e69). Joker is Wild by nature in every game; as a generator it
   has rank 0 and copies the output of the highest-charged card. Klondike: a Joker can start a
   foundation or sit on anything.
2. **Stars ★** — a fifth suit, a third colour (blue ink). 65 cards → 65! ≈ 8.2e90. Klondike gets a
   fifth foundation and 8 tableau columns; alternating colour now means "different colour".
3. **The Fool's Rank** — a 14th rank (the "Zero") below Ace. 70 cards.
4. **Moons ☾** — sixth suit… or the deck doubles (Spider-style) and every generator has a twin.

Each Ascension: the back recolours, the window's sky changes hue, the Numbering Systems extend their
normalisation to the new ranks, and a new Keeper's note appears. Ascension resets Permutations but
never lifetimeShuffles (the odometer just gets a bigger denominator).
